# Music font

`noteblocks-music.woff2` is a small subset of the **Bravura** music font by
Steinberg Media Technologies GmbH, containing only the clefs, noteheads, flags,
rests, accidentals, dots and time-signature digits the app draws.

Bravura is licensed under the SIL Open Font License 1.1 (see `OFL.txt`).
Because "Bravura" is a Reserved Font Name, this modified (subset) version is
renamed **NoteBlocks Music**, as the license requires.
